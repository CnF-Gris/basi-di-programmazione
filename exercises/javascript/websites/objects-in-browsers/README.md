# Manipolazione Oggetti nella Console

## Conoscenze acquisite

Imparare a modificare variabili dichiarate con
JavaScript nel Browser

## Come aprire la sfida

- Apri la cartella
- Apri il file `index.html` con il browser
- Modifica il file JavaScript con vscode o il tuo editor preferito
- Salva e ricarica fino a quando non hai completato l'obiettivo
