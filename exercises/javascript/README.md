# Sfide di JavaScript

## Setup ambiente

Installate un `Interprete JavaScript`, consiglio `node`, ma potete anche usare `deno` o `bun`.

Le sfide di tipo `websites` vanno completate aprendo il file `index.html` sul browser, aprendo la
cartella e facendo doppio click sul file.

## Come eseguire un file javascript con node

```bash
node file.js
```
